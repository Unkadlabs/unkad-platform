# Qor Af-Soomaali — Pilot Prompt Bank (v1)

~200 prompts in English, organized into batches matching the admin upload
tool. **Workflow:** a trusted reviewer translates each line into Somali,
then pastes the batch into Admin → Add prompts with the listed Mode /
Register / Sector / Topic settings, one prompt per line in the format:

```
Soomaali qoraalka || English text
```

(If a batch is pasted before translation, the English shows as fallback —
fine for internal testing, not for the public pilot.)

Design notes: prompts avoid eliciting personal data about third parties
(privacy guideline from the concept note), avoid politically or communally
divisive topics, and skew toward everyday registers that are absent from
news-dominated Somali web text.
